Synchronisatie via GitHub

De app bewaart je planning automatisch in een privérepository op GitHub, zodat al je toestellen dezelfde gegevens tonen. Vul dit op elk toestel eenmalig in.

De sleutel blijft op dit toestel staan en wordt nooit mee geüpload. Maak hem aan onder GitHub → Settings → Developer settings → Fine-grained tokens, met toegang tot enkel je gegevensrepository en de rechten Contents: Read and write. Deel hem met niemand.

Herstelpunten

De app bewaart automatisch momentopnames van je volledige planning. Kies een moment om naar terug te keren — je huidige toestand blijft herstelbaar via Ongedaan maken.

Deze herstelpunten staan in deze browser. Voor een echte reservekopie buiten de browser gebruik je Bewaar reservekopie (JSON) — bewaar dat bestand op een schijf of netwerkmap.
